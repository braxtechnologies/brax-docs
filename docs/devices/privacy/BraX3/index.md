## Why BraX3 exists

BraX3 aims to offer a powerful yet affordable privacy focused smartphone that you can understand, maintain and keep for years. The device supports multiple operating systems so you can choose the software that best fits your threat model, values and daily workflow.

## Key features at a glance

- Multi OS support with unlockable bootloader so you can install alternate systems when needed
- Sensible privacy defaults with fewer preinstalled apps and reduced background communication
- Serviceable hardware with published repair guides for common components like screen, battery and USB port
- Transparent documentation to help both first time users and experts diagnose issues and make informed changes
- Long term ownership mindset with community OS options and published specs
- Global connectivity, great performance, long battery life.

## Software maturity and availability

Different operating systems are at different maturity levels. Some are daily driver ready, others are work in progress. See the [OS support](./Supported%20OS/index.md) pages and each OS page for current status.
