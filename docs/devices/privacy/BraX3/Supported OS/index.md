BraX3 is designed for multi OS use. Different operating systems target different users and maturity levels.

## Supported operating systems

| OS | Type | Status (BraX3) | Docs |
|----|------|----------------|------|
| **BraxOS** | Official, Android based | Shipping default OS for BraX3 | [BraxOS on BraX3](./BraxOS/) |
| **iodéOS** | Community, Android based | Supported | [iodéOS on BraX3](./iodeos/) |
| **CipherOS** | Community, Android based | Supported | [CipherOS on BraX3](./CipherOS/) |
| **LineageOS** | Community, Android based | Supported | [LineageOS on BraX3](./LineageOS/) |
| **LunarOS** | Community, Android based | Supported | [LunarOS on BraX3](./LunarOS/) |
| **Ubuntu Touch** | Community, Linux based | Supported | [Ubuntu Touch on BraX3](./ubuntu-touch/) |

Availability, feature completeness and stability vary by OS. Always read the OS specific page before flashing.
