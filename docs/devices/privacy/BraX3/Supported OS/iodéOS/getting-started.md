!!! info "Setup overview"
    The iodéOS setup wizard follows standard Android and LineageOS flows with a few privacy specific prompts. The steps below explain each screen and where to change the setting later.

## Before you start

- Charge the device and have Wi‑Fi details and SIM available.
- If migrating from another install, prepare a Seedvault backup (optional).

## Step 1 - Select language
Choose your system language.

!!! note "How to change later ⚙️"
    Settings -> System -> Language

## Step 3 - Push notifications (microG)
iodéOS is de‑Googled by default. Enable push only if your apps require it (microG Cloud Messaging).

!!! note "How to change later ⚙️"
    Settings -> microG -> Cloud Messaging

!!! note "How to change later ⚙️"
