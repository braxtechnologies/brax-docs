---
title: Source code access
---

iodéOS source code for the BraX3 device is hosted and maintained by Brax Technologies. The code is open source and available through both Gerrit and Git.

- **Gerrit code review** - browse and review open changes: https://iodeos-review.os-source.co
- **Git repositories** - browse the full set of iodéOS repositories, including BraX3 specific projects: https://git.os-source.co/iodeOS

Use the Gerrit interface to follow active development and code review, and the Git hosting to clone the repositories locally when you build or contribute to iodéOS for BraX3.
