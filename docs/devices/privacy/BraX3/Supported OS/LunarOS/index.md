## Overview

LunarOS is a custom Android based operating system.

LunarOS is an Android-based Operating System. It includes a collection of hardware-specific software, such as drivers, bootloaders, and kernel customizations, that enables the Android operating system to function on the hardware. It acts as a bridge, providing the necessary components for custom ROMs to communicate with and control the underlying hardware.

## The Objective of LunarOS

LunarOS is intended to help developers port and maintain their custom ROM ports to the custom mobile devices. Through LunarOS, developers of custom ROMs can access major Android version updates, Vendor security patches, as well as AOSP security patches.

How about running LunarOS as a daily driver?
LunarOS includes a familiar and user-friendly UI because it’s a pure, stock version of Android—so the homescreen, settings, and overall navigation feel just like any Android phone.
However, it isn’t recommended to be used as a daily driver as it is lackluster in features, such as OTA, pre-installed apps, launcher settings, etc.
If you are purist, and don’t mind configuring your device (app/settings) almost from scratch, you may find LunarOS enjoyable due to its decluttered nature and speed.

## Is LunarOS Open Sourced?

LunarOS isn't open-sourced at the moment. Source code is provided only to security auditors and custom ROM porters.
We are actively working with our supply chain partners to open the source code of LunarOS to the public.
