---
title: Source code access
---

Ubuntu Touch source code is hosted by the UBports community in public Git repositories. BraX3 specific work will live in device and hardware repositories once the port is integrated.

- Ubuntu Touch and core projects on UBports GitLab: https://gitlab.com/ubports
- Additional mirrors and tools may exist under related organizations and hosting providers.

When the BraX3 port is published, expect one or more device specific repositories that describe:

- The BraX3 kernel and hardware adaptation layers.
- Device configuration, packaging and installer integration.

Use the official Ubuntu Touch documentation and UBports Git hosting as the source of truth for code locations and contribution workflows related to Ubuntu Touch on BraX3.
