!!! info "Setup overview"
    The Ubuntu Touch first boot experience on BraX3 walks you through a short wizard. This guide explains each step and where to adjust the setting later from the system settings app.

## Before you start

- Charge the device and have your Wi Fi details and SIM card ready.
- If you plan to restore data from another Ubuntu Touch device, make sure you have your backups available.

## Step 1 - Select language and keyboard
Choose your system language and keyboard layout.

!!! note "How to change later"
    System Settings - Language and Text

## Step 2 - Connect to Wi Fi
Select your Wi Fi network, enter the password, and connect. You can also skip and configure networking later.

!!! note "How to change later"
    System Settings - Network - Wi Fi

## Step 3 - Time zone, date and time
Confirm or adjust your time zone and whether automatic network time is enabled.

!!! note "How to change later"
    System Settings - Time and Date

## Step 4 - Lock screen security
Set a lock code to protect your device. You can choose a numeric passcode or a longer password.

!!! note "How to change later"
    System Settings - Security and Privacy - Lockscreen

## Step 5 - Location services
Decide whether apps can access location. Ubuntu Touch uses a permission system so you can later allow or deny location on a per app basis.

!!! note "How to change later"
    System Settings - Security and Privacy - Location

## Step 6 - Online accounts (optional)
If offered, you can sign in to supported online accounts so that email, calendars, and contacts can sync. You can also skip this and add accounts later.

!!! note "How to change later"
    System Settings - Accounts

## Step 7 - Appearance and theme
Pick your preferred appearance options, such as background and whether to use a dark style when available.

!!! note "How to change later"
    System Settings - Appearance

## Step 8 - Gestures and navigation
Ubuntu Touch relies on edge gestures for navigation. The intro screens show how to open the app drawer, switch apps, and access the indicator menus.

!!! note "Where to review later"
    Open the "Tutorial" app from the app drawer to replay the gesture tutorial.

## Step 9 - System updates
If an update is already available, you may be prompted to apply it. Keeping the device updated ensures you receive the latest features and security fixes.

!!! note "How to check later"
    System Settings - Updates

## Welcome

After completing the setup, you will be taken to the Ubuntu Touch home screen. From here you can:

- Swipe from the left edge to open the launcher and start apps.
- Pull down from the top to access indicators for network, sound, battery, and settings.
- Open the OpenStore app to browse and install additional applications.
