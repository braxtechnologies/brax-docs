## Project

??? question "What is Ubuntu Touch?"
    Ubuntu Touch is a community developed, open source mobile operating system based on Ubuntu. It is maintained by the UBports Foundation and contributors around the world.

??? question "Why bring Ubuntu Touch to BraX3?"
    BraX3 is a privacy focused device, and Ubuntu Touch offers a non Android, Linux based experience with strong privacy properties. Together they give users another option that avoids Google Play Services and proprietary vendor skins.

??? question "Who maintains Ubuntu Touch?"
    Ubuntu Touch is maintained by the UBports Foundation and its community. Brax contributes device specific work, testing and documentation for BraX3.

## Operating system

??? question "How is Ubuntu Touch different from Android based OS options?"
    Ubuntu Touch uses a full Ubuntu userland and a different app model. Apps are confined by AppArmor, installed from the OpenStore and do not rely on Google Play Services by default.

??? question "Will my favorite Android apps work?"
    Ubuntu Touch does not run native Android apps directly. Some Android apps may work via community solutions that run an Android container, but the primary app ecosystem is OpenStore.

??? question "How are system updates delivered?"
    System updates are delivered over the air. When BraX3 is supported, you will receive Ubuntu Touch updates through the built in Updates settings.

??? question "Can I switch back to another OS later?"
    Yes. As long as you have images for another supported OS (such as BraxOS or iodéOS), you can reflash your device following the corresponding installation guides.

## Privacy and security

??? question "How does Ubuntu Touch protect my privacy?"
    Apps are isolated using AppArmor, permissions are explicit, and the system does not ship with third party trackers or Google Play Services.

??? question "Is Ubuntu Touch open source?"
    Yes. Most of the stack is open source, and source code is hosted on public Git platforms under the UBports and related organizations.

??? question "Does Ubuntu Touch include Google Play Services or microG?"
    No. Ubuntu Touch does not bundle Google Play Services or microG. Some community projects may integrate Android compatibility separately, but it is not part of the base system.

## Usage and troubleshooting

??? question "What if a feature does not work on BraX3 yet?"
    New device ports often start with known limitations. Check the BraX3 Ubuntu Touch device notes and UBports documentation for a list of supported and known problematic features.

??? question "Where can I get help as a BraX3 user?"
    You can use the Brax community channels for device specific questions and the UBports forums, Telegram and Matrix rooms for general Ubuntu Touch support.

??? question "How often are Ubuntu Touch updates released?"
    Ubuntu Touch uses a rolling style release model built on top of Ubuntu LTS bases. Updates are published regularly with security fixes and new features.
